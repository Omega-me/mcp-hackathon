# Data Model: Hobbies CRUD Operations

**Feature**: 006-hobbies-crud
**Date**: November 20, 2025
**Purpose**: Define data structures, entities, and relationships for Hobbies CRUD feature

## Core Entities

### Hobby

Represents a hobby or leisure activity in the system.

**Attributes**:

| Field       | Type   | Required        | Constraints                  | Description                        |
| ----------- | ------ | --------------- | ---------------------------- | ---------------------------------- |
| id          | string | Yes (generated) | Non-empty, unique            | Server-generated unique identifier |
| name        | string | Yes             | 1-255 chars, trimmed, unique | Hobby name (unique identifier)     |
| description | string | No              | Max 1000 chars, trimmed      | Optional description of the hobby  |
| createdAt   | string | Yes (generated) | ISO 8601 timestamp           | Record creation timestamp          |
| updatedAt   | string | Yes (generated) | ISO 8601 timestamp           | Record last update timestamp       |

**Business Rules**:

- Hobby names must be unique across all hobbies (case-insensitive)
- Hobby name cannot be empty after trimming
- Description is optional but has a maximum length constraint
- Timestamps are managed by the API server
- ID is generated by the API server on creation

**Relationships**:

- Hobby ← Person (assumed): Hobbies may be associated with people (managed by people feature)
- Hobby is a standalone entity with no direct foreign key relationships in this feature

## Validation Schemas (Zod)

import { z } from "zod";

/**
 * Schema for get all hobbies parameters
 * Currently accepts optional parameters for future pagination/filter support

export const GetAllHobbiesParamsSchema = z
  .object({
    page: z.number().int().positive().optional(),
    limit: z.number().int().positive().max(100).optional(),

**Validation Rules**:

- `page`: Optional positive integer
- `limit`: Optional positive integer, max 100
- `filter`: Optional string for future text search

### Create Hobby Schema

```typescript
/**
 * Schema for creating a hobby
 */
export const CreateHobbySchema = z.object({
  name: z
    .string()
    .min(MIN_NAME_LENGTH, ERROR_MESSAGES.NAME_REQUIRED)
    .max(MAX_NAME_LENGTH, ERROR_MESSAGES.NAME_TOO_LONG)
    .trim(),
  description: z
    .string()
    .max(MAX_DESCRIPTION_LENGTH, ERROR_MESSAGES.DESCRIPTION_TOO_LONG)
    .trim()
    .optional(),
});

export type CreateHobbyInput = z.infer<typeof CreateHobbySchema>;
```

**Validation Rules**:

- `name`: Required, 1-255 characters, trimmed
- `description`: Optional, max 1000 characters, trimmed

**Constants Used**:

- `MIN_NAME_LENGTH = 1`
- `MAX_NAME_LENGTH = 255`
- `MAX_DESCRIPTION_LENGTH = 1000`
- `ERROR_MESSAGES` from constants.ts

## API Contract Specifications

### Base Configuration

**Base URL**: `http://10.138.80.113:5000`  
**Authentication**: JWT Bearer token in Authorization header  
**Content-Type**: `application/json`

---

### 1. Get All Hobbies

**Endpoint**: `GET /hobbies`  
**Authentication**: Required

**Request**:

- Query Parameters (future support):
  - `page` (optional): Page number for pagination
  - `limit` (optional): Items per page (max 100)
  - `filter` (optional): Text search filter

**Response** (200 OK):

```json
{
  "data": [
    {
      "id": "hobby-uuid-1",
      "name": "Photography",
      "description": "Capturing moments through lens",
      "createdAt": "2025-11-20T10:00:00.000Z",
      "updatedAt": "2025-11-20T10:00:00.000Z"
    },
    {
      "id": "hobby-uuid-2",
      "name": "Hiking",
      "description": null,
      "createdAt": "2025-11-20T11:00:00.000Z",
      "updatedAt": "2025-11-20T11:00:00.000Z"
    }
  ]
}
```

**Error Responses**:

- 401 Unauthorized: Missing or invalid JWT token
- 500 Internal Server Error: Server-side error

---

### 2. Create Hobby

**Endpoint**: `POST /hobbies`  
**Authentication**: Required

**Request Body**:

```json
{
  "name": "Photography",
  "description": "Capturing moments through lens"
}
```

**Response** (201 Created):

```json
{
  "data": {
    "id": "hobby-uuid-1",
    "name": "Photography",
    "description": "Capturing moments through lens",
    "createdAt": "2025-11-20T10:00:00.000Z",
    "updatedAt": "2025-11-20T10:00:00.000Z"
  }
}
```

**Error Responses**:

- 400 Bad Request: Invalid request body or validation failure
- 401 Unauthorized: Missing or invalid JWT token
- 409 Conflict: Hobby name already exists
- 500 Internal Server Error: Server-side error

---

### 3. Get Hobby by ID

**Endpoint**: `GET /hobbies/{id}`  
**Authentication**: Required

**Path Parameters**:

- `id`: Hobby unique identifier

**Response** (200 OK):

```json
{
  "data": {
    "id": "hobby-uuid-1",
    "name": "Photography",
    "description": "Capturing moments through lens",
    "createdAt": "2025-11-20T10:00:00.000Z",
    "updatedAt": "2025-11-20T10:00:00.000Z"
  }
}
```

**Error Responses**:

- 400 Bad Request: Invalid ID format
- 401 Unauthorized: Missing or invalid JWT token
- 404 Not Found: Hobby does not exist
- 500 Internal Server Error: Server-side error

---

### 4. Update Hobby

**Endpoint**: `PUT /hobbies/{id}`  
**Authentication**: Required  
**Method**: PUT (full replacement)

**Path Parameters**:

- `id`: Hobby unique identifier

**Request Body**:

```json
{
  "name": "Wildlife Photography",
  "description": "Capturing animals in their natural habitat"
}
```

**Response** (200 OK):

```json
{
  "data": {
    "id": "hobby-uuid-1",
    "name": "Wildlife Photography",
    "description": "Capturing animals in their natural habitat",
    "createdAt": "2025-11-20T10:00:00.000Z",
    "updatedAt": "2025-11-20T12:30:00.000Z"
  }
}
```

**Error Responses**:

- 400 Bad Request: Invalid ID format or request body
- 401 Unauthorized: Missing or invalid JWT token
- 404 Not Found: Hobby does not exist
- 409 Conflict: Hobby name already exists (different hobby)
- 500 Internal Server Error: Server-side error

---

### 5. Delete Hobby

**Endpoint**: `DELETE /hobbies/{id}`  
**Authentication**: Required

**Path Parameters**:

- `id`: Hobby unique identifier

**Response** (200 OK):

```json
{
  "success": true,
  "message": "Hobby deleted successfully"
}
```

**Error Responses**:

- 400 Bad Request: Invalid ID format
- 401 Unauthorized: Missing or invalid JWT token
- 404 Not Found: Hobby does not exist
- 409 Conflict: Hobby has dependencies (e.g., associated with people)
- 500 Internal Server Error: Server-side error

## Error Response Format

**Standard Error Response**:

```json
{
  "success": false,
  "error": "Clear, actionable error message"
}
```

**Common Error Scenarios**:

| Scenario             | Status | Error Message                                                       |
| -------------------- | ------ | ------------------------------------------------------------------- |
| Missing auth token   | 401    | "Authentication required. Please login first using the login tool." |
| Invalid hobby ID     | 400    | "Invalid hobby ID provided"                                         |
| Hobby not found      | 404    | "Hobby not found"                                                   |
| Duplicate hobby name | 409    | "A hobby with this name already exists"                             |
| Name too long        | 400    | "Hobby name must be 255 characters or less"                         |
| Description too long | 400    | "Description must be 1000 characters or less"                       |
| Empty name           | 400    | "Hobby name is required"                                            |
| Network error        | N/A    | "Network error occurred while communicating with API"               |
| API failure          | 500    | "API request failed"                                                |
